Sole backend engineer on a 7-person graduation project. Built the entire FastAPI backend from scratch — 9 route groups, a full async SQLAlchemy stack with 14 ORM models, JWT auth with a token blocklist, and Alembic-managed migrations with a database seeder.

The AI layer runs a production RAG pipeline with a clean factory pattern: LLM provider (Gemini, OpenAI, Cohere, Ollama), embedding model, and vector store (pgvector or Qdrant) are all swappable at runtime via a single environment variable — no application code changes.

The optional AGENT_ENABLED=true JSON-Planner agentic layer decides per-turn whether retrieval is necessary — cutting redundant vector searches on follow-up questions and improving response coherence.

Platform serves three roles: students chat with uploaded documents or AI tutors scoped to their enrolled subjects; instructors upload and manage course materials and preview the bot before it goes live; admins monitor platform health, usage analytics, and response feedback across all subjects.
